# Gestion des étudiants

## Description
Application Python permettant de calculer la moyenne et le résultat des étudiants.

## Technologies utilisées
- Python 3
- Pytest
- Git
- GitHub

## Installation
Cloner le dépôt :
git clone https://github.com/meriamlakraimi/gestion_etudiants.git
Accéder au projet :
cd gestion_etudiants
Créer un environnement virtuel :
python3 -m venv venv
Installer les dépendances :
pip install -r requirements.txt

## Exécution
python3 src/main.py

## Tests
python3 -m pytest -v
